# Профильные навыки движка и проверка

## Подключение по задаче
После выбора макета найди навыки в текущем каталоге и прочитай нужный SKILL.md; уже установленные помощники подключай самостоятельно. Не считай установку MCP, программы и навыка одним действием. Перед использованием проверь реальную программу/инструменты и версию; каталог не доказывает рабочий запуск.

| Задача | Помощник | Граница |
| --- | --- | --- |
| Three.js | threejs | Сцена, камеры, свет, анимация, браузерная проверка; телефон только по задаче |
| Blender: запуск и API | blender-core | Контекст bpy, выполнение в открытой сцене или отдельном процессе |
| Blender: опорные позы и движение | blender-animation | Фазы/таймлайн, интерполяция, контакты; не заставляет делать чистовую анимацию |
| Blender: камера и свет | blender-lighting-lookdev | Читаемость, кадрирование, базовый свет/тени |
| Blender: черновой проход | blender-rendering | Минимальный пригодный режим и фактический экспорт |
| Blender: состояние движения | ecc:blender-motion-state-inspection или blender-motion-state-inspection | Оси, root/facing, координаты, контакты, скольжение; после измерений визуальное подтверждение |
| Blender: геометрия | blender-asset-qa | Только относящиеся к задаче проблемы объектов; для макета render-профиль без требований игровой/печатной модели |
| Режиссёрский разбор | sw-scene-craft и доступный reviewer | Причинность, география, внимание и темп по [staging-review.md](staging-review.md) |

Достаточность определяется сценой. Не читай все модули Blender и не создавай риг, физику, игровую топологию или волосы только потому, что это есть в помощнике. Базовый цикл: первый грубый проход → проверка → ограниченные исправления.

## Установка отсутствующего помощника
Сначала проверь уже установленное и доступные прямые средства. Ищи через find-skills/skill-installer по действующему разрешению. Прочитай источник, требования, лицензию и исполняемые вспомогательные файлы, зафиксируй выбранную ревизию. Не запускай установщики всего набора, если нужны несколько модулей; установка MCP/платного сервиса/новой программы оценивается отдельно.

Проверенный источник-кандидат для модулей Blender — [EL4CTEO/blender-skills](https://github.com/EL4CTEO/blender-skills), сторонний MIT-набор для Blender 5.2+. Установка конкретной машины и её результаты фиксируются в проектном манифесте вне этого навыка, а не подразумеваются для всех пользователей. Номер версии примера не заменяет проверку совместимости. Для официальных API используй документацию фактической версии Blender/Three.js.

Upstream-модули могут ссылаться на дополнительные навыки: устанавливай только реально необходимое по текущему разрешению либо используй имеющиеся средства. Не объявляй отсутствующий модуль прочитанным.

## Безопасное исполнение и скорость
Работай с копией или сохранённым checkpoint текущей сцены. Генерические turntable/QA-скрипты могут заменять служебные коллекции, цвета или настройки; сначала выясни область действия, не применяй их вслепую к пользовательскому master. Не выполняй сброс открытой сцены ради smoke test.

Для проверки сюжета достаточно грубого прохода. Дешёвый плоский режим не доказывает мировую схему света; если проверяются отбрасываемые тени, используй режим, который их реально показывает. Если Blender не запускается, сообщи установленный факт, проверь альтернативу и не трать время на скрытую повторную установку/бесконечные запуски.

short-drama-review в установленной версии может разбирать только текстовые наблюдения о производстве. Его подключение не создаёт просмотр видео. Реальный осмотр выполняет агент доступными средствами; затем reviewer сопоставляет наблюдения с текущим сценарием. Недоступное движение/прослушивание отмечай UNKNOWN. Отдельная техническая проверка не заменяет режиссёрскую.
