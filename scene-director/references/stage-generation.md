# 4. Пакет, сервис и модель


Выбери достаточный доступный маршрут по [references/model-selection.md](model-selection.md) в пределах решений. Для открытого выбора сервиса рекомендуемый по умолчанию Higgsfield; пользовательский выбор имеет приоритет. Проверь каталог, реальные входы, ограничения и получение файла; наличие аккаунта не подразумевается навыком.

Отдельно называй модель, сервис и способ подключения. Сравнивай полную одинаковую задачу: длительность, формат, качество, звук и все входы. Цены — из актуальных котировок; неизвестное не заменяй старым тарифом или выдуманной наценкой.

Храни авторский/отправленный промпты и привязки @имён. Структура: SCENE CONTEXT → REFERENCES → SHOTS → CAMERA LAW → GRADE AND AUDIO → CONSTRAINTS. Назови источник внешности/палитры, сохраняемое движение/время и заменяемое черновое исполнение. Готовое изображение оживляй с одного достаточного источника, если не выбрано иное; достраивание скрытого и смешение входов проверяй по reference-strategy.md. Не обещай независимый перенос движения/внешности без поддержки модели.

Перед запуском сверь active_contract, точные слова/языки, покрытие, фактические входы и полную цену. Передаваемый запрос совпадает с показанным. Загрузка и выполнение — по [references/execution.md](execution.md).


# 5. Полная проба и 6. Финал


Полная проба покрывает весь согласованный эпизод, героев, ключевые действия, раскрытие и нужный звук. Выбери самый дешёвый поддерживаемый режим выбранной модели, сохраняющий проверяемость. Не сокращай покрытие/нужные входы ради цены. Для нескольких частей посчитай полную сборку; тестовый фрагмент вместо эпизода — только по соответствующей задаче.

Показывай пакет и запрашивай решение по [review-modes.md](review-modes.md): before_paid требует ответа по актуальному пакету до списания, final_only использует конкретное предварительное разрешение. Пакет включает действие, точные слова/говорящих, материалы, сервис/модель, входы, формат, качество, звук и актуальную цену. Запускай в пределах бюджета и числа задач. Job ID сохраняй сразу; при таймауте проверяй созданный job без слепого повтора.

Проверь реальный файл и каждую запрошенную правку по staging-review.md. Метки «получено», «проверено» и «выбрано пользователем» различаются. Покадровая проверка не подтверждает непрерывный просмотр или звук. Исправляй конкретный дефект монтажом, звуком или локальной правкой, если это сохраняет принятое; апскейл не исправляет действие. Новая генерация требует действующего разрешения и может изменить остальное.

Финализацию draft используй только при реальной поддержке. Принятую пробу можно отдать готовой без новой оплаты. Выполни нужные стыки, паузы, сведение и выбранные субтитры. Готовым называй собранный файл с границами проверки; при недоступном монтаже передай исходники/план, указав незавершённость.
