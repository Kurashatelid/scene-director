# Происхождение и выбор правил

Основание MVP: пользовательский маршрут и учебные материалы SuperComputer Academy в доступной при разработке папке Downloads/higgsfield. Папка материалов может отсутствовать на другой машине; основные правила включены в SKILL.md, обращаться к PDF на каждом шаге не требуется.

- Create and Edit Assets — Visual Companion, стр. 15–20, 24: кастинг, лист персонажа, сохранение идентичности при правках, геометрия локации, свет и камера.
- Direct Your Own Scene, стр. 3–10: замысел, отдельные роли визуальных/видео/голосовых референсов, постановка с заменителями, сохранение выбранной сцены, структура итогового промпта.
- Product Images and Ads — Visual Companion, стр. 3–6: точный предмет, выбранные материалы и небольшая первая проба.

При наличии соответствующих установленных навыков читай их по задаче:

| Навык | Когда нужен |
| --- | --- |
| sw-scene-craft, sw-dialogue | Драматургический поворот, диалог и комедийная пауза |
| sw-sitcom-comedy | Комедийный контраст, подготовка и развязка шутки; для короткой сцены только подходящие приёмы |
| find-skills | Поиск и оценка внешнего навыка при отсутствии нужной компетенции в локальном каталоге |
| scripting-and-storyboarding | Таблица изображения и звука, длительность, монтажный план |
| short-form-video-script | Начало, темп и понятность короткого ролика; без обязательных CTA/петель |
| threejs | Работающий макет и интерактивная камера; доступен также в ~/.agents/skills |
| cineimage-soul | Промпты локации и изображений |
| character-consistency | Отдельные идентичности и листы персонажей |
| video-prompt-director | Роли материалов, пространство и причинное действие |
| cinedance-lite | Авторский режим, кинематографические камера/свет/действие |
| ugc-video-creator | Только подходящие UGC-сцены, отдельные референсы |
| ai-voiceover, ai-music-and-sound | Голос, исполнение и план звуковых слоёв |
| ai-video | Выбор способа генерации по задаче |
| short-drama-review | Автоматический разбор результата: наблюдение, влияние, необходимые правки и ограничения проверки |
| skill-creator | После проверки результата: оценка необходимости минимального улучшения самого scene-director и валидация изменений |

Не загружай все навыки сразу. Подходящие установленные навыки применяй автоматически, без предварительного меню. Если вспомогательный навык недоступен, используй метанавык поиска по правилам SKILL.md, продолжай независимую работу и сообщай только о существенных ограничениях.

Известные конфликты: пользовательский стандарт карточки в references/character-card.md имеет приоритет над иными листами: одно изображение с крупным лицом и четырьмя полнофигурными ракурсами, видимые лица на фигурах закрыты белым пятном; точное @имя едино. В CINEIMAGE 2.7 в исходном ZIP отсутствовал references/clean-midtones-examples.md: не утверждай, что прочитал его, и не требуй его для всего маршрута. Узкие навыки могут требовать только промпт или описывать ручную генерацию — используй их приёмы, выполняя реальную задачу доступными инструментами. Каталоги моделей, цены и правовые заявления в старых навыках требуют отдельной проверки при необходимости; не копируй их как факты.
