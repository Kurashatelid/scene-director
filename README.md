# Scene Director — Режиссёр сцены

Навык для AI-ассистента: создание постановочного видео и анимации от идеи до финальной генерации. Версия: **0.2.4**.

## Как работает

1. Сценарий изображения и звука: замысел, действия, реплики и финал.
2. Макет / аниматик в Three.js или Blender: камера, свет, тени, микродвижения, черновой звук и сокращение по хронометражу готового макета. Three.js подходит для быстрого интерактивного просмотра; Blender — для постановочного аниматика с редактируемой сценой `.blend` и экспортом полного прохода камеры. Для плоской анимации допустим простой аниматик из рисунков или слоёв.
3. Визуальные материалы: локация, персонажи и предметы с постоянными @именами и общей библиотекой.
4. Пакет для генератора: макет, референсы и промпт; сравнение доступных моделей по пригодности и полной стоимости.
5. Полная пробная версия эпизода в самом экономичном подходящем режиме выбранной модели.
6. Правки и финальная генерация или сборка.

Любой этап можно пропустить или использовать готовый результат. Навык отмечает, что при этом остаётся непроверенным. Платные генерации выполняются по разрешению пользователя.

## Режим участия автора

В начале производства навык предлагает выбрать: согласовывать каждый этап, посмотреть все наработки перед платной генерацией или увидеть результат в конце. Во втором режиме подготовка, внутренние проверки и исправления проходят автоматически; затем автор получает весь пакет с материалами, промптом и стоимостью для решения перед платным запуском. Выбор сохраняется для продолжения работы. Режим просмотра результата в конце действует в пределах заранее разрешённых расходов и объёма запусков.

Подробности: [режимы участия и общий показ пакета](scene-director/references/review-modes.md).

## Оживление готового изображения

Для пролёта по фотографии, картине или иллюстрации навык сначала предлагает один источник внешности и текст камеры. Создание макета не обязывает передавать его в генератор. Дополнительные референсы добавляются под конкретную задачу; отдельно учитываются источник палитры и достраивание скрытых поверхностей. Один снимок не гарантирует точную геометрию.

Изменение формы неподвижного объекта считается существенным нарушением, даже когда движение камеры выполнено. Подробнее: [стратегия референсов и проверка сохранения объекта](scene-director/references/reference-strategy.md).

## Анимация и стили

Можно выбрать рисованную 2D-анимацию, аниме, стилизованную 3D-анимацию, стоп-моушен/пластилиновый/кукольный вид, бумажную перекладку, коллаж, живописную или акварельную подачу, графическую анимацию. Список открыт; допустим смешанный формат с фотографической сценой.

Навык отдельно фиксирует внешний вид и характер движения, переносит их в персонажей, локацию, макет и видеопромпт и проверяет сохранение стиля в пробном ролике. Выбор Blender для макета не определяет стиль финала. Подробнее: [анимационное направление](scene-director/references/animation.md).

## Установка

Скопируйте папку `scene-director` целиком в каталог навыков вашей среды. Для Codex это обычно `~/.codex/skills/scene-director`. Точка входа — `scene-director/SKILL.md`. В новом чате вызовите `$scene-director` или попросите создать видео.

## Подключение генерации

Для генерации видео подключите **Higgsfield** через доступный плагин или интеграцию и войдите в свой аккаунт. Это рекомендуемый сервис по умолчанию. Можно использовать другой подключённый сервис, если его инструменты и модели поддерживают нужные материалы и сценарий.

Установка навыка не подключает сервис автоматически, не предоставляет аккаунт или кредиты. Сценарий, макет и материалы можно готовить до подключения. Доступность конкретных инструментов зависит от среды ассистента.

## Дополнительные навыки и материалы

CINEIMAGE, CINEDANCE и UGC Video Creator входят в репозиторий как встроенные справочные модули. Другие установленные вспомогательные навыки подключаются по задаче; соответствия перечислены в `scene-director/references/sources.md`. Для интерактивного макета используется Three.js, для постановочного аниматика — Blender. Для режима Blender нужна доступная в среде программа Blender: проверяются версия и запуск; установка навыка сама по себе её не устанавливает. Оба режима выдают видео полного прохода камеры. Управление камерой с телефона предусмотрено в Three.js; для Blender требуется отдельный проверенный мост управления.

Библиотека персонажей, локаций и предметов хранится вне папки навыка. Для её повторного использования предоставьте ассистенту доступ к папке и индексу библиотеки. Пользовательские видео, изображения и данные аккаунтов в этот пакет не включены.

## Улучшения

Навык не обучается автоматически. После работы он может предложить обобщённые улучшения инструкций. Отправка в GitHub выполняется только после согласия пользователя и настройки адреса репозитория; частные материалы по умолчанию не отправляются.


## Встроенная учебная библиотека

В `scene-director/references/training/` включены **102 извлечённых текстовых блока** из восьми предоставленных PDF (промпты, шаблоны и части длинных примеров), а также три уникальных исходных навыка: CINEIMAGE 2.7, CINEDANCE LITE 3.0 / Seedance Prompter и UGC Video Creator. Для работы с ними исходные PDF и отдельная установка этих трёх навыков не нужны. Индекс распределяет материалы по этапам; правила адаптации сохраняют решения пользователя и учитывают различия сервисов.

Библиотека содержит примеры камеры, локаций, света, персонажей, предметной съёмки, UGC, сборки видеопромпта и точечных правок. В каждой записи указаны исходный документ и страница; машиночитаемый индекс помогает найти пример. Исходные изображения, PDF и пользовательские материалы не включены. Обозначения моделей и интерфейсов в уроках не заменяют актуальный каталог сервиса. Происхождение и сведения о лицензиях исходных навыков указаны в `source-manifest.json`; сборнику целиком не назначается лицензия стороннего модуля.


## Сравнение стоимости и качества подключения

Перед генерацией навык сравнивает доступные маршруты: одну модель через внутренний MCP-сервер и через Higgsfield, а также подходящие альтернативы. В таблице — стоимость одинакового полного запроса с референсами, возможности управления, ограничения и рекомендация для сцены. MCP обозначает способ подключения, а не отдельную модель: Higgsfield также может работать через MCP. Цены получают из актуальных котировок; мнение о качестве отделяется от результатов реального просмотра и отзывов пользователя. Платное сравнение нескольких сервисов автоматически не запускается.


## После готового видео

Навык сразу предлагает обложку и готовое описание для Instagram. Этот шаг можно пропустить. При доступном подключении с правом публикации он может разместить согласованный пост в выбранном аккаунте; подключённая аналитика сама по себе не даёт такого права. Если API нет или размещение невозможно, пользователь получает видео, обложку и описание для ручной публикации. Создание материалов и разрешение на публикацию учитываются отдельно.
